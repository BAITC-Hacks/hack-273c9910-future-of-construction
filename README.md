# 🏛️ Аким на 5 часов

**Интерактивный симулятор городских решений для Астаны.**
У вас 100 единиц бюджета, 5 решений и 5 районов с реальными проблемами. Выберите, что строить и где, и посмотрите, как изменится качество жизни горожан — прежде всего в самых слабых районах.

> Строительство будущего начинается не с бетона, а с правильного решения: **что** строить, **где** и **в каком порядке**.

---

## 💡 Проблема

Городской бюджет всегда ограничен, а потребности районов разные: где-то не хватает школ, где-то задыхаются от угольного дыма частного сектора, где-то рвутся теплосети. Решения часто принимаются «по среднему», и отстающие районы остаются позади.

Жителям и студентам сложно понять, **почему** город выбирает одно, а не другое, и какие компромиссы стоят за каждым тенге.

## ✅ Решение

«Аким на 5 часов» превращает городское планирование в понятную игру с честной математикой:

- 🎯 **Реальные ограничения**: бюджет 100, ровно 5 решений, не больше двух мер одного направления.
- ⏳ **Время имеет значение**: крупные стройки (ЛРТ, теплосети) дают эффект с задержкой и за 8 кварталов раскрываются не полностью.
- 🔗 **Меры влияют друг на друга**: есть синергии (бонусы за удачные связки) и несовместимости.
- ⚖️ **Справедливость встроена в оценку**: итог учитывает не только средний уровень города, но и самый слабый район, а за каждый критический провал начисляется штраф.
- 🤖 **Честный AI**: все цифры считает детерминированный движок, а языковая модель только объясняет результат человеческим языком. Приложение полностью работает без AI-ключа.

---

## 🎮 Как играть

1. Посмотрите на карту районов: у каждого своя оценка и свои «красные зоны».
2. Выберите меру и, если она районная, укажите, **где строим**.
3. Следите за полосой бюджета и индексом качества жизни: он пересчитывается после каждого шага.
4. Соберите «чек» из 5 решений и нажмите **«Завершить управление»**.
5. Получите итог: было → стало, изменения по районам, сработавшие синергии и снятые критические провалы.

## 🏙️ Модель города

**5 районов Астаны**: Есиль, Алматы, Сарыарка, Байконур, Нура. У каждого своя доля населения и стартовые показатели.

**10 индикаторов качества жизни** (шкала 0–100):

| Направление | Индикаторы |
|---|---|
| 🚌 Транспорт | Разгрузка дорог · Доступность общественного транспорта |
| 🌳 Экология | Озеленение · Качество воздуха |
| 🏫 Социальная сфера | Школы и детсады · Поликлиники |
| 🛡️ Безопасность | Безопасность улиц · Безопасность дорожного движения |
| 🔧 Городские сервисы | Надёжность ЖКХ · Скорость решения обращений |

**14 мер**, районных и общегородских:

| Мера | Масштаб | Цена | Задержка |
|---|---|---:|---:|
| Выделенные полосы для автобусов | район | 18 | 2 кв. |
| Умные светофоры | город | 22 | 2 кв. |
| Линия ЛРТ / расширение | район | 30 | 4 кв. |
| Парк / сквер | район | 15 | 2 кв. |
| Перевод частного сектора на чистое топливо | район | 25 | 3 кв. |
| Городская программа озеленения и ветрозащитных полос | город | 20 | 4 кв. |
| Школа + детсад | район | 24 | 3 кв. |
| Центр семейного здоровья / поликлиника | район | 20 | 3 кв. |
| Дворовые спорт-хабы | район | 10 | 1 кв. |
| Освещение и камеры Safe City | район | 12 | 1 кв. |
| Безопасные переходы и школьные зоны | район | 10 | 1 кв. |
| Единая цифровая платформа обращений | город | 14 | 1 кв. |
| Модернизация тепло- и водосетей | район | 28 | 4 кв. |
| Аварийные бригады ЖКХ + раннее оповещение | город | 16 | 1 кв. |

**Синергии** (+2 к индикатору):
- Выделенные полосы + умные светофоры → разгрузка дорог.
- Safe City + цифровая платформа обращений → безопасность улиц.
- Чистое топливо + городское озеленение → качество воздуха.

**Несовместимости**:
- Выделенные полосы и ЛРТ нельзя выбрать вместе.
- Парк и школу нельзя строить в одном районе.
- Чистое топливо и модернизацию теплосетей нельзя вести в одном районе одновременно.

## 📐 Математика

**Эффект с учётом задержки** (горизонт 8 кварталов):

```
реализованный эффект = полный эффект × (8 − задержка) / 8
```

**Оценка района**: взвешенная сумма 10 индикаторов (веса 0.09–0.11).

**Итоговый индекс города**:

```
Score = 0.7 × D_avg + 0.3 × min(D_d) − N_crit
```

- `D_avg`: средняя оценка районов, взвешенная по доле населения;
- `min(D_d)`: оценка самого слабого района, поэтому игнорировать отстающих невыгодно;
- `N_crit`: число индикаторов ниже критического порога 40, минус 1 балл за каждый.

Стартовый индекс города: **52.56**. Контрольный сценарий из тестов поднимает его примерно до **56.5** и снимает оба критических провала.

**Оптимизатор** перебирает все допустимые комбинации мер и районов и детерминированно находит лучшие сценарии, так что любой результат можно проверить и воспроизвести.

## 🧱 Архитектура

```
src/
├── domain/        типы, константы, веса индикаторов
├── data/          районы, меры, синергии, несовместимости
├── engine/        чистые функции: валидация, эффекты, симуляция, скоринг, оптимизатор
├── ai/            AI-аналитик (только объясняет, ничего не считает), любой OpenAI-совместимый провайдер
├── lib/           схемы Zod, правила доступности мер, сессия
├── components/    UI: игра «потрать бюджет», районы, карточки мер, чек, итог
├── app/           Next.js App Router: страницы и API (/api/simulate, /api/optimize, /api/analyze)
└── tests/         Vitest: базовый сценарий, валидатор, скоринг, симуляция, оптимизатор
```

**Принципы:**
- Движок состоит из чистых детерминированных функций: одинаковый ввод всегда даёт одинаковый результат.
- Данные отделены от логики: новый район, меру или правило можно добавить без переписывания движка.
- Один и тот же движок работает и в браузере (мгновенный предпросмотр), и на сервере (официальный расчёт).

**Стек:** Next.js 15 · React 19 · TypeScript · Tailwind CSS v4 · Zod · Recharts · lucide-react · Vitest.

## 🚀 Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

```bash
npm test          # тесты движка
npm run build     # production-сборка
```

**AI-аналитик (необязательно).** Скопируйте `.env.example` в `.env.local` и укажите ключ:

```
OPENAI_API_KEY=...
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
```

Без ключа симуляция, скоринг и оптимизатор работают полностью; отключается только текстовое объяснение от AI.
